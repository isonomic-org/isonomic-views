# Security

## Reporting a vulnerability

Report a security problem in isonomic-views privately, through GitHub's private
vulnerability reporting: open this repository's **Security** tab and choose
**Report a vulnerability**. That opens a private advisory that only the
maintainers can read.

Please do not open a public issue, pull request or discussion for a security
problem, and do not disclose it publicly until a fix has been released.

## What to include

- What the problem is and what an attacker could do with it.
- The version, commit or build you tested.
- Steps to reproduce it, or a proof of concept.

## What to expect

We acknowledge a report within five working days, keep you informed while we
investigate, and credit you in the advisory if you want to be named.
